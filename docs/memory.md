# Memory

## Record

- **User** — role, expertise, standing preferences.
- **Feedback** — guidance given about how to work, including the reasoning. A
  correction without its *why* becomes cargo cult.
- **Project** — goals and constraints not derivable from the code or history.
  Convert relative dates to absolute ones.
- **Reference** — external resources: dashboards, tickets, URLs.

## Do not record

- Anything the repo already states: structure, past fixes, git history, the
  contents of `AGENTS.md`.
- Anything that only matters inside one conversation.

## Maintenance

Prefer updating an existing memory over adding a near-duplicate. Delete memories
that turn out to be wrong. A memory naming a file, function, or flag is a claim
about the present — verify it still exists before acting on it.
